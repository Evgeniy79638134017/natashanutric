# Сайт нутрициолога Натальи Ерёменко

## О проекте
Профессиональный сайт для нутрициолога-биохакера Натальи Ерёменко (Благовещенск). Цель — привлечение клиентов на консультации и программы здоровья (30–180 дней). Выход на холодный рынок за пределы ближнего круга.

## Стек
Astro 5, Tailwind CSS 4, TypeScript, MDX (контент), React (формы/фильтры), Vercel

## Дизайн «Нежный персик»
- Фон страниц: gradient(135deg, #FDECD0 → #FBE4E0 → #FCE4EC)
- Альт-секции: gradient(180deg, #FFF8F2 → #FFF0F0)
- Кнопки: gradient(135deg, #7CB59D → #5EA882), тень rgba(124,181,157,0.27)
- Заголовки: #2E4A3A, текст: #555555, текст-light: #888888
- Карточки: rgba(255,255,255,0.85)
- Акцент (бейджи): #F4A7B4, бейджи фон: #E8F5EE
- Футер: #2E4A3A
- Шрифты: Montserrat для заголовков, Source Sans 3 для текста
- Стиль: современный, нежный персиково-розовый, много воздуха, скруглённые углы
- Mobile-first, адаптивный

## Структура страниц
/ — Главная (hero, специализации, шаги работы, кейсы, мифы, CTA)
/about — Об эксперте
/programs — Каталог программ с фильтрами
/programs/[slug] — Страница программы (из MDX)
/cases — Кейсы клиентов
/consultation — Запись на консультацию + тарифы
/blog — Статьи
/contacts — Контакты

## Контент программ — в MDX файлах /src/content/programs/
## Статьи — в MDX файлах /src/content/blog/

## Команды
npm run dev — localhost:4321
npm run build — сборка
npm run astro check — проверка типов

## Стандарты
- TypeScript для всех файлов
- Только Tailwind CSS (без inline-стилей)
- Компоненты в PascalCase
- Изображения WebP, ленивая загрузка
- SEO: мета-теги, OG-теги на каждой странице
- НЕ писать медицинские утверждения «лечит», «избавляет» — только «помогает», «поддерживает», «способствует»
- Коммит после каждого этапа
